# Full Path To Public-Safe Artifact

This example exercises ClaimWright's initial workflow.

## Workflow

1. Capture a private claim.
2. Assign a claim state.
3. Retrieve candidate citations.
4. Preserve accepted, rejected, and unresolved candidates.
5. Estimate confidence dimensions.
6. Run adversarial review.
7. Search for stale related claims.
8. Prepare branch comparison.
9. Apply public/private checks.
10. Run the academic-publication integrity review, including human disposition
    of material similarity matches.
11. Record final human publication approval.

## Branch Pattern

| Branch | Use When | Risk |
|---|---|---|
| Conservative | Evidence is narrow or reputational risk is high | Lower coverage, possible missed synthesis |
| Balanced | Evidence supports scoped public claim | Moderate review burden |
| Expansive | The claim is promising but evidence is incomplete | Higher conceptual drift and publication risk |

## Required Output

- public-safe artifact draft;
- claim records;
- citation review records;
- rejected-citation trail;
- adversarial review memo;
- stale-claim task list;
- publication-integrity review record;
- publication gate result.
